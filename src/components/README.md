# 组件目录

组件按职责分组，页面只组合所需模块。

## 目录

| 目录 | 用途 |
|---|---|
| `layout/` | 导航、页脚、文章卡片、侧栏等页面骨架 |
| `controls/` | 搜索、分页、目录、主题和悬浮控件 |
| `common/` | 按钮、图标、图片、Markdown 和分页等通用模块 |
| `widget/` | 侧栏中的公告、日历、分类、标签、个人资料和站点信息 |
| `features/` | 页面转场、首页首屏、代码交互、公式和图片查看等增强功能 |
| `pages/` | 搜索页和相册页等特定页面组件 |
| `misc/` | 文章许可、推荐阅读和分享海报 |

## 约定

- Astro 组件负责静态结构和页面布局，Svelte 组件负责交互状态。
- 路径导入优先使用 `@components`、`@assets`、`@utils` 等别名。
- 公共组件保持可复用，不写入旧站身份或旧域名。
- 涉及页面切换的事件监听必须在离开页面时清理。
- 新增功能应优先复用现有组件和配置，不为单个页面复制一套界面。
